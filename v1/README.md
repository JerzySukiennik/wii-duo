# Wii-Duo

Two-player co-op games for one TV, played with two Wii Remotes (one per player) in Chrome via WebHID. Also runs with keyboard and mouse.

Games: Paper Plane Squadron, Space Station Repair, Heist Duo, Bomb Squad, Lumberjacks, Boxing Sparring, plus a copy of HUSH (single player horror).

- Pair each Wiimote with the computer first (hold 1+2), then press "Connect Wiimotes".
- Chrome or Edge only (Safari has no WebHID).
- `test.html` shows live buttons, tilt and IR pointer for each remote.
- Keyboard mode: P1 WASD tilt, F/G buttons, mouse aim, Z/X/C swing. P2 arrows tilt, Enter/RShift buttons, IJKL aim, B/N/M swing.
- Home returns to the menu, Minus re-centers tilt.

Sounds in `hush/` are from Freesound (CC0, stingers CC-BY 3.0 by SirBedlam), see `hush/sounds/CREDITS.md`. Textures: Poly Haven (CC0).
