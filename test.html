Wiimote Test ~*~

Pair both remotes with the OS first (hold 1+2), then connect them here.
Keyboard remotes: P1 = WASD tilt, F=A, G=B, Q=1, E=2, mouse = pointer  ·  P2 = arrows tilt, Enter=A, RShift=B, IJKL = pointer Real remotes: check that tilting right makes the roll value go the direction you expect, and that the pointer dot follows where you aim.
